# Frontend - College Complaint Management System

Built with **React 19 + Vite + Tailwind CSS + Lucide Icons + Motion**.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```

The frontend will run at `http://localhost:5173`. By default, API requests to `/api/*` will proxy to your local backend at `http://localhost:5000`.

## 🌐 Deploy to Vercel

1. Import your GitHub repository in Vercel.
2. Set **Root Directory** to `frontend`.
3. Add Environment Variable:
   - `VITE_API_URL`: Your deployed backend URL (e.g. `https://your-backend.onrender.com`).
4. Click **Deploy**.
